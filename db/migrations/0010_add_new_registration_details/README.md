**Why:** a Neuzulassung order must survive between checkout, identity verification, filing and every poll, with its owner, address, bank account, eVB number and Teil II code encrypted; it also needs a place for the verification it waits on and a VIN lookup for the duplicate warning.
**Breaks without it:** the repository cannot store a Neuzulassung order (it has no plate or security codes for the required columns), and the verification id and deadline have nowhere to live; de-registration is unaffected.
**Live table:** safe; only drops `NOT NULL` and adds nullable columns and checks that every stored de-registration already satisfies (its columns are all filled, the new ones empty). The index build briefly blocks writes on a large table (none is large yet). `down.sql` deletes every Neuzulassung order (with its payment, history and token), so it runs in dev and CI only, as the runner enforces: until Neuzulassung is on sale those are the seed's.
